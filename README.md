## 🛡️ OSINT Framework v2.0

Framework intelijen sumber terbuka (OSINT) yang dirancang untuk membantu para praktisi keamanan siber, analis data, dan komunitas programmer dalam mengumpulkan informasi digital secara cepat dan akurat. Dibangun dengan fokus pada kecepatan dan antarmuka terminal yang modern.

---

## 🚀 Fitur
*   **📱 Phone Tracker Pro:** Melacak informasi provider, lokasi negara, zona waktu, dan format internasional secara mendalam.
*   **🌐 IP Intelligence:** Ekstraksi data IP Address lengkap termasuk ISP, koordinat Maps, dan deteksi organisasi.
*   **📸 Instagram Scraper:** Mengambil metadata profil publik Instagram tanpa memerlukan login (Anonim).
*   **⚡ Modular Architecture:** Struktur kode yang rapi sehingga mudah untuk ditambah modul baru.

---

## 🛠️ Instalasi

**Pastikan Anda memiliki Python 3.8 ke atas. Clone repository ini dan install dependensinya :**

1. Clone repository
```
git clone https://github.com/123tool/OSINT-Framework-v2.0.git
```
2. Masuk ke direktori
```
cd OSINT-Framework-v2.0
```
3. Install dependensi
```
pip install -r requirements.txt
```
4. Eksekusi file
```
python main.py
```

## Navigasi Menu :

- Menu 1 : Masukkan nomor HP (Gunakan kode negara, contoh: 628123xxx).
- Menu 2 : Masukkan alamat IP target (Contoh: 8.8.8.8).
- Menu 3 : Masukkan username Instagram target tanpa @.
- Menu 0 : Keluar dari aplikasi secara aman.
